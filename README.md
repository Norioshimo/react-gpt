# Proyecto OpenAI Examples

Este repositorio contiene una aplicación full-stack que demuestra distintos usos de la API de OpenAI. Incluye ejemplos de generación de imágenes, audios, asistentes y más.

## Tecnologías utilizadas

- Backend: NestJS

- Frontend: React con Tailwind CSS

- Integración: API de OpenAI

## Estructura del proyecto

- backend/ → Servidor NestJS que gestiona las peticiones y se conecta a OpenAI.

- frontend/ → Interfaz en React + Tailwind para interactuar con los ejemplos.

## Funcionalidades

- Generación de imágenes con modelos de OpenAI.

- Conversión y generación de audios.

- Ejemplos de asistentes y chat interactivo.

- Otros casos de uso de la API.


## Documentación

Para más detalles sobre los endpoints y parámetros disponibles, consulta la documentación oficial de OpenAI.
